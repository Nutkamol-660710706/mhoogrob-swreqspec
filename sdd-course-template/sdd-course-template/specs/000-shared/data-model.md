# Data model ร่วม (ทุกฟีเจอร์อ้างถึง)

เขียนเฉพาะ entity ที่มากกว่า 1 ฟีเจอร์ใช้ร่วมกัน entity ที่ใช้ในฟีเจอร์เดียวให้อยู่ใน spec ของฟีเจอร์นั้น

## <Entity เช่น Patient>
| ฟิลด์ | ชนิด | จำเป็น | หมายเหตุ |
|-------|------|--------|----------|
|       |      |        |          |

กฎที่ทุกฟีเจอร์ต้องทำตาม
- ระบุ ID ภายในที่ใช้อ้างอิง (เช่น ใช้ HN ไม่เก็บเลขบัตรประชาชน)
- ระบุฟิลด์ที่เป็นข้อมูลส่วนบุคคลตาม PDPA และการเข้าถึงต้องมี audit log
