# Feature: สมัครสมาชิกและเข้าสู่ระบบ
Spec ID: SPEC-GYM-002 | Source: SRS v1.0 ข้อ 3.2 | Use case: UC-02
Owner: ทีมพัฒนาระบบ | Status: Draft v1 | Updated: 2026-09-20
Depends on: - | Reviewed by: -

## Goal
ผู้ใช้งานสามารถสมัครสมาชิกใหม่และเข้าสู่ระบบเพื่อใช้งานฟังก์ชันที่เกี่ยวข้องกับการออกกำลังกายได้อย่างปลอดภัยและถูกต้อง

## Scope
### In scope
- สมัครสมาชิกด้วยข้อมูลพื้นฐานที่จำเป็น
- ตรวจสอบความถูกต้องของข้อมูลสมัครสมาชิก
- สร้างบัญชีผู้ใช้งานใหม่
- เข้าสู่ระบบด้วยข้อมูลที่ถูกต้อง
- เก็บ session หรือ token ของผู้ใช้งาน
- ออกจากระบบเมื่อสิ้นสุดการใช้งาน
### Out of scope
- ฟังก์ชันลืมรหัสผ่านหรือรีเซ็ตรหัสผ่าน
- การยืนยันตัวตนแบบหลายปัจจัย (MFA)
- การจัดการข้อมูลส่วนตัวเพิ่มเติมนอกเหนือจากข้อมูลหลัก

## Constraints
- CON-002-01 ต้องใช้ HTTPS เพื่อปกป้องข้อมูลผู้ใช้งานระหว่างส่งผ่าน
- CON-002-02 ต้องมี Authentication และ Authorization ตาม Role
- CON-002-03 ข้อมูลรหัสผ่านต้องถูกจัดเก็บในรูปแบบที่ปลอดภัย

## Requirements
- FR-01-01 ระบบต้องให้ผู้ใช้งานกรอกข้อมูลสมัครสมาชิกที่จำเป็น เช่น ชื่อผู้ใช้ อีเมล หรือเบอร์โทรศัพท์ รหัสผ่าน และยืนยันรหัสผ่าน
- FR-01-02 ระบบต้องตรวจสอบความครบถ้วนและรูปแบบของข้อมูลก่อนสร้างบัญชีใหม่
- FR-01-03 ระบบต้องปฏิเสธการสมัครสมาชิกเมื่อข้อมูลซ้ำหรือข้อมูลไม่ถูกต้องตามข้อกำหนด
- FR-01-04 ระบบต้องแจ้งผลการสมัครสมาชิกให้ผู้ใช้งานทราบอย่างชัดเจน
- FR-01-05 ระบบต้องให้ผู้ใช้งานเข้าสู่ระบบด้วยอีเมลหรือเบอร์โทรศัพท์และรหัสผ่าน
- FR-01-06 ระบบต้องตรวจสอบความถูกต้องของข้อมูลเข้าสู่ระบบก่อนอนุญาตให้เข้าถึงระบบ
- FR-01-07 ระบบต้องปฏิเสธการเข้าสู่ระบบเมื่อข้อมูลไม่ตรงกันหรือบัญชีถูกปิดใช้งาน
- FR-01-08 ระบบต้องสร้าง session หรือ token หลังจากเข้าสู่ระบบสำเร็จ
- FR-01-09 ระบบต้องให้ผู้ใช้งานสามารถออกจากระบบได้อย่างปลอดภัย

## Quality Requirements
- NFR-01 ระบบต้องสื่อสารผ่าน HTTPS เพื่อความปลอดภัยของข้อมูล
- NFR-02 ระบบต้องมีการ Authentication ที่เชื่อถือได้ก่อนให้ใช้งาน
- NFR-03 ระบบต้องมี Authorization ตาม Role ของผู้ใช้งาน
- NFR-04 ระบบต้องป้องกันการเข้าถึงข้อมูลหรือการกระทำที่ไม่ได้รับอนุญาต
- NFR-07 ระบบต้องคำนึงถึงการคุ้มครองข้อมูลส่วนบุคคลของผู้ใช้งาน

## Acceptance Criteria
- [ ] AC-002-01 (FR-01-01, FR-01-02)
      Given ผู้ใช้งานเปิดหน้าสมัครสมาชิก
      When ผู้กรอกข้อมูลครบถ้วนและถูกต้อง
      Then ระบบต้องสร้างบัญชีผู้ใช้งานใหม่และแจ้งความสำเร็จ
- [ ] AC-002-02 (FR-01-05, FR-01-06)
      Given ผู้ใช้งานมีบัญชีที่ถูกต้อง
      When เข้าสู่ระบบด้วยข้อมูลที่ตรงกัน
      Then ระบบต้องอนุญาตให้เข้าสู่ระบบและสร้าง session
- [ ] AC-002-03 (FR-01-03, FR-01-07)
      Given ผู้ใช้งานกรอกข้อมูลไม่ถูกต้องหรือข้อมูลซ้ำ
      When ส่งแบบฟอร์มสมัครหรือเข้าสู่ระบบ
      Then ระบบต้องปฏิเสธและแสดงข้อผิดพลาดที่เหมาะสม

## Assumptions and Open Questions
- ASM-002-01 ระบบถือว่าผู้ใช้งานต้องมีบัญชีก่อนใช้งานฟังก์ชันอื่น ๆ
- ASM-002-02 ผู้ใช้งานสามารถใช้งานในอุปกรณ์มือถือได้ตาม NFR-08
- Q-002-01 ต้องกำหนดรูปแบบข้อมูลที่รับรองสำหรับการลงทะเบียน เช่น อีเมลหรือเบอร์โทรศัพท์ใดใช้ได้บ้าง
- Q-002-02 ต้องกำหนดนโยบายการล็อกอินซ้ำหรือจำนวนครั้งที่ลองเข้าสู่ระบบผิดพลาดก่อนล็อก
