# Feature: แนะนำสถานที่ออกกำลังกาย
Spec ID: SPEC-GYM-001 | Source: SRS v1.0 ข้อ 3.1 | Use case: UC-01
Owner: ทีมพัฒนาระบบ | Status: Draft v1 | Updated: 2026-09-09
Depends on: ระบบจัดการข้อมูลสถานที่ออกกำลังกาย, ระบบระบุตำแหน่งผู้ใช้งาน | Reviewed by: -

## Goal
ผู้ใช้งานสามารถค้นหาและเลือกสถานที่ออกกำลังกายที่เหมาะสมกับความต้องการ โดยพิจารณาจากระยะทาง ประเภทสถานที่ จำนวนผู้ใช้บริการ ระดับความหนาแน่น และสิ่งอำนวยความสะดวก เพื่อช่วยในการตัดสินใจเดินทางไปออกกำลังกายได้อย่างเหมาะสม

## Scope
### In scope
- ค้นหาสถานที่ออกกำลังกายใกล้ตำแหน่งของผู้ใช้งาน
- แนะนำสถานที่ออกกำลังกายที่เหมาะสม
- กรองสถานที่ตามระยะทาง
- กรองสถานที่ตามประเภทสถานที่
- กรองสถานที่ตามสิ่งอำนวยความสะดวก
- จัดอันดับสถานที่ตามเงื่อนไขของผู้ใช้งาน
- แสดงจำนวนผู้ใช้บริการปัจจุบัน
- แสดงระดับความหนาแน่นของสถานที่
- แสดงข้อมูลสิ่งอำนวยความสะดวก
- แสดงรายละเอียดของสถานที่ออกกำลังกาย
- แสดงที่อยู่ของสถานที่
- แสดงเวลาเปิด-ปิดของสถานที่
- แสดงระยะทางจากผู้ใช้งานไปยังสถานที่
- แสดงเวลาที่ข้อมูลจำนวนผู้ใช้บริการถูกอัปเดตล่าสุด
### Out of scope
- การจองสถานที่ออกกำลังกาย ถือว่าดำเนินการโดย Use Case อื่น
- การชำระค่าบริการสถานที่ออกกำลังกาย ถือว่าดำเนินการโดย Use Case อื่น
- การนำทางไปยังสถานที่ออกกำลังกาย ถือว่าดำเนินการโดยระบบแผนที่หรือ Use Case อื่น
- การจัดการข้อมูลสถานที่ออกกำลังกายของผู้ให้บริการ ถือว่าดำเนินการโดยระบบจัดการข้อมูลสถานที่
- การบันทึกประวัติการออกกำลังกาย ถือว่าดำเนินการโดย Use Case อื่น

## Constraints
- <DOM-xxx> <ข้อบังคับจากกฎหมาย/ระเบียบ ที่โค้ดตรวจได้>
- <IF-xxx> <ระบบภายนอกที่ฟีเจอร์นี้แตะ ทิศทางข้อมูล และทำอย่างไรเมื่อมันไม่ตอบ>
- <CON-xxx> <เทคโนโลยีหรือมาตรฐานที่บังคับ>

## Requirements
- FR-GYM-01 ระบบต้องแสดงรายการสถานที่ออกกำลังกายที่อยู่ใกล้ตำแหน่งของผู้ใช้งาน (UC-01 Main Flow 2)
- FR-GYM-02 ระบบต้องแสดงรายการสถานที่ที่ระบบแนะนำเมื่อผู้ใช้งานไม่ได้กำหนดเงื่อนไขการค้นหา (UC-01 3a)
- FR-GYM-03 ระบบต้องให้ผู้ใช้งานกำหนดระยะทางสำหรับการค้นหาสถานที่ (UC-01 Main Flow 3)
- FR-GYM-04 ระบบต้องให้ผู้ใช้งานเลือกประเภทของสถานที่ออกกำลังกาย (UC-01 Main Flow 3)
- FR-GYM-05 ระบบต้องให้ผู้ใช้งานเลือกสิ่งอำนวยความสะดวกที่ต้องการ (UC-01 Main Flow 3)
- FR-GYM-06 ระบบต้องจัดอันดับสถานที่ตามเงื่อนไขที่ผู้ใช้งานกำหนด (UC-01 Main Flow 4)
- FR-GYM-07 ระบบต้องจัดอันดับสถานที่ตามระยะทางเมื่อผู้ใช้งานไม่ได้กำหนดเงื่อนไข (UC-01 3a)
- FR-GYM-08 ระบบต้องจัดอันดับสถานที่ตามความนิยมเมื่อผู้ใช้งานไม่ได้กำหนดเงื่อนไข (UC-01 3a)
- FR-GYM-09 ระบบต้องจัดอันดับสถานที่ตามจำนวนผู้ใช้บริการปัจจุบันเมื่อผู้ใช้งานไม่ได้กำหนดเงื่อนไข (UC-01 3a)
- FR-GYM-10 ระบบต้องแสดงจำนวนผู้ใช้บริการของสถานที่ที่ค้นพบ (UC-01 Main Flow 5)
- FR-GYM-11 ระบบต้องแสดงระดับความหนาแน่นของสถานที่เป็น "น้อย", "ปานกลาง" หรือ "มาก" (UC-01 Main Flow 5)
- FR-GYM-12 ระบบต้องใช้ข้อมูลจำนวนผู้ใช้บริการล่าสุดเมื่อไม่มีข้อมูลปัจจุบัน (UC-01 5a)
- FR-GYM-13 ระบบต้องแสดงเวลาที่ข้อมูลจำนวนผู้ใช้บริการล่าสุดถูกอัปเดต (UC-01 5a)
- FR-GYM-14 ระบบต้องแสดงสิ่งอำนวยความสะดวกของสถานที่ที่มีข้อมูล (UC-01 Main Flow 6)
- FR-GYM-15 ระบบต้องแสดงรายการสิ่งอำนวยความสะดวกที่ไม่มีข้อมูลเป็นสถานะ "ไม่มีข้อมูล" (UC-01 7a)
- FR-GYM-16 ระบบต้องแสดงรายละเอียดสถานที่เมื่อผู้ใช้งานเลือกสถานที่ (UC-01 Main Flow 7-8)
- FR-GYM-17 ระบบต้องแสดงที่อยู่ของสถานที่ที่ผู้ใช้งานเลือก (UC-01 Main Flow 8)
- FR-GYM-18 ระบบต้องแสดงเวลาเปิด-ปิดของสถานที่ที่ผู้ใช้งานเลือก (UC-01 Main Flow 8)
- FR-GYM-19 ระบบต้องแสดงระยะทางจากตำแหน่งผู้ใช้งานไปยังสถานที่ (UC-01 Main Flow 8)
- FR-GYM-20 ระบบต้องแจ้งให้ผู้ใช้งานเปิดการระบุตำแหน่งเมื่อระบบไม่สามารถระบุตำแหน่งได้ (UC-01 2a)
- FR-GYM-21 ระบบต้องให้ผู้ใช้งานเลือกพื้นที่ด้วยตนเองเมื่อไม่สามารถระบุตำแหน่งได้ (UC-01 2a)
- FR-GYM-22 ระบบต้องแจ้งข้อผิดพลาดเมื่อไม่สามารถเชื่อมต่อฐานข้อมูลสถานที่ได้ (UC-01 4a)
- FR-GYM-23 ระบบต้องให้ผู้ใช้งานลองค้นหาสถานที่อีกครั้งเมื่อไม่สามารถเชื่อมต่อฐานข้อมูลได้ (UC-01 4a)
- FR-GYM-24 ระบบต้องแสดงข้อมูลจำนวนผู้ใช้บริการล่าสุดเมื่อไม่สามารถอัปเดตข้อมูลแบบ Real-time ได้ (UC-01 5a Exception Flow)
- FR-GYM-25 ระบบต้องระบุว่าข้อมูลจำนวนผู้ใช้บริการที่แสดงไม่ใช่ข้อมูล Real-time เมื่อไม่สามารถอัปเดตข้อมูลได้ (UC-01 5a Exception Flow)

## Quality Requirements
- NFR-GYM-01 ระบบต้องแสดงผลการค้นหาสถานที่ภายใน 2 วินาที ภายใต้เงื่อนไขการใช้งานปกติ (NFR-PERF-01)
- NFR-GYM-02 ระบบต้องปกป้องข้อมูลตำแหน่งและข้อมูลส่วนตัวของผู้ใช้งานด้วยการควบคุมการเข้าถึงข้อมูล (NFR-SEC-01)
- NFR-GYM-03 ระบบต้องให้บริการค้นหาสถานที่อย่างต่อเนื่องตามระดับความพร้อมใช้งานที่ทีมกำหนด (NFR-AVL-01)

## Acceptance Criteria
- [ ] AC-GYM-01 (FR-GYM-01)
      Given ผู้ใช้งานเข้าสู่หน้าค้นหาสถานที่และระบบสามารถระบุตำแหน่งได้
      When ผู้ใช้งานค้นหาสถานที่ใกล้เคียง
      Then ระบบต้องแสดงรายการสถานที่ออกกำลังกายพร้อมระยะทางของแต่ละสถานที่
- [ ] AC-GYM-02 (FR-GYM-03, FR-GYM-06)
      Given ผู้ใช้งานอยู่ในหน้าค้นหาสถานที่
      When ผู้ใช้งานกำหนดระยะทางและประเภทสถานที่
      Then ระบบต้องแสดงเฉพาะสถานที่ที่ตรงตามเงื่อนไขที่กำหนด

## Assumptions and Open Questions
- ASM-01 ระบบถือว่าผู้ใช้งานเข้าสู่ระบบก่อนใช้งานฟีเจอร์นี้
- ASM-02 ระบบถือว่าข้อมูลสถานที่ออกกำลังกายมีอยู่ในฐานข้อมูลหรือแหล่งข้อมูลภายนอกที่ระบบสามารถเข้าถึงได้
- ASM-03 ระบบถือว่าระดับความหนาแน่นสามารถคำนวณจากจำนวนผู้ใช้บริการตามเกณฑ์ที่ทีมกำหนด
- ASM-04 หากไม่มีข้อมูลจำนวนผู้ใช้บริการแบบ Real-time ระบบจะใช้ข้อมูลล่าสุดที่มีแทน
- ASM-05 ผู้ใช้งานสามารถเลือกพื้นที่ด้วยตนเองได้เมื่อไม่อนุญาตให้ระบบเข้าถึงตำแหน่ง
- Q-01 ต้องกำหนดเกณฑ์จำนวนคนสำหรับระดับ "น้อย / ปานกลาง / มาก" -> ต้องถาม Product Owner
- Q-02 ต้องกำหนดว่า "ความนิยม" ของสถานที่จะคำนวณจากข้อมูลใด -> ต้องถาม Product Owner
- Q-03 ต้องกำหนดระดับ Availability ที่ระบบต้องรองรับ เช่น 99.0%, 99.5% หรือ 99.9% -> ต้องถามทีม Infrastructure / Product Owner
- Q-04 ต้องกำหนดแหล่งข้อมูลจำนวนผู้ใช้บริการแบบ Real-time -> ต้องถามทีม Backend / Product Owner
- Q-05 ต้องกำหนดระยะเวลาที่ยอมรับได้สำหรับข้อมูลจำนวนผู้ใช้บริการที่ถือว่าเป็น "ข้อมูลล่าสุด" -> ต้องถาม Product Owner
- Q-06 ต้องกำหนดว่าการค้นหาสถานที่ต้องรองรับพื้นที่ครอบคลุมระดับใด เช่น จังหวัดหรือทั่วประเทศ -> ต้องถาม Product Owner
